# Nika – Dyreappen

En varm, chatbasert hundeapp for hele familien.

## Første MVP
- Onboarding via chat (navn, rase, alder)
- Personlig hundeprofil
- Luftetur med hendelsesregistrering
- Måltidsplan
- Familieoversikt
- QR-ID-konsept

Demoen er under utvikling. Ingen GPS-sporing eller offentlig ID-tjeneste er aktivert ennå.
